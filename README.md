# ระบบเช็คชื่อกลุ่มศึกษาอัลกุรอาน (หะละเกาะห์) • Halaqah Quran Attendance System

เว็บแอปพลิเคชันสำหรับบันทึกและติดตามการเข้าร่วมกลุ่มศึกษาอัลกุรอาน (หะละเกาะห์) รองรับอาจารย์ผู้รับผิดชอบ 40 กลุ่ม และนักศึกษา 514 คน (ชาย 109 คน, หญิง 405 คน) พร้อมแดชบอร์ดสรุปผลเชิงสถิติ และการส่งออกรายงานเป็นไฟล์ Excel, Word, และ PDF โดยใช้ **Google Sheet** เป็นฐานข้อมูล เชื่อมต่อผ่าน Google Apps Script Web App และพร้อม Deploy ไปยัง **Vercel**

---

## 🌟 ฟีเจอร์หลัก (Features)

### 1. สำหรับอาจารย์ประจำกลุ่ม (Teacher / Group Leader)
* **เลือกระบุอาจารย์ประจำกลุ่ม:** ระบบบันทึกกลุ่มที่รับผิดชอบไว้ในเครื่อง ไม่ต้องเลือกใหม่ทุกครั้ง
* **เลือก วัน-เดือน-ปี ในสไตล์ Minimal:**
  * เลือกได้สะดวกรวดเร็ว มีปุ่มลัด (วันนี้, เมื่อวาน, 7 วันที่แล้ว)
  * รองรับการเช็คชื่อย้อนหลังและดูประวัติของวันก่อนหน้าได้ทันที
* **ตารางเช็คชื่อที่ใช้งานง่าย:**
  * แสดงรหัสนักศึกษา และชื่อ-นามสกุล ชัดเจน
  * ปุ่มสถานะ 3 รูปแบบ: **[ มา ] (เขียว)**, **[ ขาด ] (แดง)**, **[ ลา ] (ส้ม)**
  * มีปุ่มลัด **"มาทุกคน" (Mark All Present)** เพื่อความรวดเร็วในการบันทึก
* **สถิติและประวัติย้อนหลังของกลุ่ม:**
  * คำนวณอัตราการเข้าร่วม (%) ประจำวันและภาพรวมของกลุ่มแบบ Real-time
  * มีปฏิทินย้อนหลัง แสดงจำนวนครั้งที่เคยเช็คชื่อไว้แล้ว

### 2. สำหรับผู้ดูแลระบบ (Admin Dashboard)
* **สรุปผลเชิงสถิติ (KPI Metrics):**
  * อัตราการเข้าร่วมภาพรวม (%)
  * ยอดรวมการเช็คชื่อ (คน-ครั้ง)
  * จำนวนนักศึกษาและอาจารย์ทั้งหมดในระบบ
* **มุมมองรายงานหลายมิติ (Multi-dimensional Views):**
  * 📊 **ภาพรวม (Overview):** กลุ่มที่มีอัตราการเข้าสูงสุด และสัดส่วน มา/ขาด/ลา
  * 📅 **สรุปรายวัน (Daily):** สถิติการมาเรียนในแต่ละวันที่มีการจัดกิจกรรม
  * 📆 **สรุปรายเดือน (Monthly):** สรุปจำนวนครั้งและอัตราการมาเรียนในแต่ละเดือน
  * 🎓 **สรุปรายอาจารย์ (By Teacher):** สถิติแยกตามอาจารย์และกลุ่มที่รับผิดชอบ
  * 👤 **สรุปรายนักศึกษา (By Student):** สถิติรายบุคคล (รหัส, ชื่อ, จำนวนครั้งที่มา/ขาด/ลา)
  * 📋 **ประวัติบันทึกทั้งหมด (All Records Log):** บันทึกการเช็คชื่ออย่างละเอียด
* **ตัวกรองอัจฉริยะ (Smart Filters):**
  * ค้นหารหัสนักศึกษา, ชื่อ-นามสกุล, หรือชื่ออาจารย์
  * กรองตามเพศ (ชาย / หญิง), ชั้นปี (ปี 2, ปี 3, ปี 4) หรือระบุรายอาจารย์
* **การส่งออกรายงาน (Export System):**
  * 📊 **Excel (.xlsx):** ส่งออกไฟล์สมุดงาน 3 ชีต (บันทึกรายคน, สรุปรายอาจารย์, สรุปรายนักศึกษา)
  * 📄 **Word (.docx):** เอกสารสรุปรายงานพร้อมหัวเรื่อง สถิติ และตารางอย่างสวยงาม
  * 🖨️ **PDF / พิมพ์รายงาน:** รูปแบบเอกสารคมชัด จัดรูปแบบหน้ากระดาษพร้อมสั่งพิมพ์หรือบันทึกเป็น PDF

7. `ชื่อกลุ่ม (Group)`
8. `ชั้นปี (Year Level)`
9. `เพศ (Gender)`
10. `วันเวลาที่บันทึก (Timestamp)`

## 🚀 ขั้นตอนการติดตั้งและ Deploy

### ขั้นตอนที่ 1: ติดตั้ง Google Apps Script ใน Google Sheet (1 นาที)
1. เปิด [Google Sheet](https://docs.google.com/spreadsheets/d/1S8XLzMp1w9CdeW5rydKmTYvvL_ie-ecFIfQbqi_P_D0/edit)
2. ไปที่เมนู **ส่วนขยาย (Extensions)** > **Apps Script**
3. ลบโค้ดเดิมออกทั้งหมด แล้วนำโค้ดในไฟล์ `google-apps-script.js` ไปวาง
4. กดปุ่มบันทึก (Ctrl + S)
5. กดปุ่ม **ทำให้ใช้งานได้ (Deploy)** > **การทำให้ใช้งานได้รายการใหม่ (New deployment)**
6. เลือกประเภท: **เว็บแอป (Web app)**
   * คำอธิบาย: `Halaqah Quran API`
   * ดำเนินการในฐานะ: **ตัวฉันเอง (Me)**
   * ใครมีสิทธิ์เข้าถึง: **ทุกคน (Anyone)** *(สำคัญมาก)*
7. กด **ทำให้ใช้งานได้ (Deploy)** และอนุมัติสิทธิ์ (Authorize access)
8. คัดลอก **URL ของเว็บแอป (Web app URL)** เก็บไว้

### ขั้นตอนที่ 2: นำโค้ดขึ้น GitHub
1. เปิด Terminal ในโฟลเดอร์โปรเจกต์นี้
2. สั่งคำสั่ง Git:
```bash
git init
git add .
git commit -m "feat: ระบบเช็คชื่อหะละเกาะห์ อัลกุรอาน เชื่อมต่อ Google Sheet"
git branch -M main
git remote add origin https://github.com/USERNAME/REPO_NAME.git
git push -u origin main
```

### ขั้นตอนที่ 3: Deploy ไปยัง Vercel
1. เข้าไปที่ [Vercel](https://vercel.com) แล้วล็อกอินด้วย GitHub
2. กด **Add New...** > **Project**
3. เลือก Repository ที่เพิ่ง Push ขึ้นไป
4. ในส่วน **Environment Variables** ให้เพิ่มตัวแปร:
   * `NEXT_PUBLIC_GOOGLE_SHEET_ID`: `1S8XLzMp1w9CdeW5rydKmTYvvL_ie-ecFIfQbqi_P_D0`
   * `NEXT_PUBLIC_APPS_SCRIPT_URL`: *(ใส่ Web App URL ที่ได้จากขั้นตอนที่ 1)*
5. กด **Deploy** รอประมาณ 1 นาที เว็บแอปพลิเคชันจะพร้อมใช้งานทันทีทั่วโลก!
